# TraceLife 前端骨架设计文档

> 本文档定义项目的 UI 体系、组件复用规则、样式系统、目录边界。所有代码实现必须严格遵守。

---

## 1. 视觉方案

### 1.1 设计语言：Material Design 3

Flutter 内置 Material 3 支持，MD3 是整个 UI 体系的基础。禁止在 MD3 之外自创视觉语言。

**核心原则：**
- 颜色、字体、间距、圆角全部来自 Theme，禁止硬编码
- 暗色模式自动跟随系统，无需手动维护两套样式
- 动画曲线统一用 MD3 预定义曲线

### 1.2 配色系统

颜色全部通过 `ThemeData.colorScheme` 表达，使用 Flutter 的 `MaterialColorBuilder` 生成。

| Token | 用途 | MD3 映射 |
|-------|------|---------|
| `primary` | 主色：导航栏选中、按钮、链接 | `colorScheme.primary` |
| `onPrimary` | 主色上的文字/图标 | `colorScheme.onPrimary` |
| `surface` | 卡片、列表项背景 | `colorScheme.surface` |
| `onSurface` | 正文文字颜色 | `colorScheme.onSurface` |
| `surfaceContainerHighest` | 输入框、分割线背景 | `colorScheme.surfaceContainerHighest` |
| `outline` | 边框、分隔线 | `colorScheme.outline` |
| `tertiary` | 强调色：正数日卡片、心情颜色 | `colorScheme.tertiary` |
| `error` | 错误状态 | `colorScheme.error` |

**色彩生成策略：**
- 浅色模式：使用带蓝色调的方案（`seedColor: const Color(0xFF4F46E5)`）
- 深色模式：Flutter 自动从 seed color 推导
- 禁止在 Widget 代码中直接写 `Color(0xFF...)` 或 `Colors.blue`

### 1.3 字体系统

使用 MD3 默认字体（Roboto + Noto Sans SC），无需额外引入。

| 层级 | TextTheme | 用途 |
|------|-----------|------|
| H1 | `headlineLarge` | 首页日期、大标题 |
| H2 | `headlineSmall` | 页面标题 |
| 正文 | `bodyLarge` | 日记内容、表单输入 |
| 次要 | `bodyMedium` | 描述文字、提示 |
| 标注 | `labelLarge` | 按钮文字、Tab 标签 |
| 小字 | `bodySmall` | 时间戳、辅助信息 |

### 1.4 间距系统

基于 4px 网格，通过 `AppSpacing` 常量类统一管理：

```dart
class AppSpacing {
  static const double xs = 4;
  static const double sm = 8;
  static const double md = 12;
  static const double lg = 16;
  static const double xl = 24;
  static const double xxl = 32;
}
```

禁止在 Widget 中直接写 `SizedBox(width: 16)`、`EdgeInsets.all(12)` 等 — 全部引用 `AppSpacing.xxx`。

### 1.5 圆角和阴影

- 卡片圆角：`AppSpacing.md` (12px) — 通过 `Card` 主题统一配置
- 按钮圆角：`AppSpacing.sm` (8px) — 通过 `FilledButton` 主题统一配置
- 输入框圆角：`AppSpacing.sm` (8px) — 通过 `InputDecoration` 主题统一配置
- 阴影层：MD3 elevation 体系（`Surface` 组件内置），禁止手动 `BoxShadow`

### 1.6 图标

- 使用 Flutter Material Icons（`Icons.xxx`），不引入第三方图标库
- 按钮图标尺寸统一 20dp，列表图标 24dp
- 正数日 emoji 使用 Unicode 文本，非图标

## 2. 技术方案

（详见立项文档第 9 节，此处只列关键约束）

| 层 | 技术 | 约束 |
|----|------|------|
| 状态管理 | Riverpod v2 | 所有 UI 状态通过 Provider 暴露，Widget 不接受非 const 构造参数 |
| 路由 | GoRouter | 所有导航走 router，禁止 `Navigator.push` 硬跳 |
| 主题 | Material 3 + ThemeExtension | 禁止硬编码样式值 |
| 本地化 | Flutter l10n (ARB) | 所有用户可见字符串放在 .arb 文件中 |
| 数据模型 | freezed | 所有 Entity 和 DTO 使用 freezed 生成 |
| 数据库 | sqflite + Repository | Widget 不直接操作 SQLite |

## 3. 共享 UI 组件库

### 3.1 组件清单（V1 需要）

| 组件 | 位置 | 职责 | 复用场景 |
|------|------|------|---------|
| `AppScaffold` | `shared/widgets/app_scaffold.dart` | 统一页面骨架 + SafeArea | 所有页面 |
| `AppCard` | `shared/widgets/app_card.dart` | 统一卡片容器 | 正数日卡片、日记摘要卡片 |
| `AppEmptyState` | `shared/widgets/app_empty_state.dart` | 空状态提示 | 无日记时、无正数日时 |
| `AppSectionHeader` | `shared/widgets/app_section_header.dart` | 分组标题 + 可选操作按钮 | Today 页各分区 |
| `AppConfirmDialog` | `shared/widgets/app_confirm_dialog.dart` | 确认弹窗 | 删除确认 |
| `AppFloatingActionButton` | 用 Flutter 内置 FAB + 主题 | 新增操作 | 写日记、加正数日 |
| `MoodIcon` | `shared/widgets/mood_icon.dart` | 心情图标 1-5 | 日记编辑、日记摘要 |

### 3.2 组件设计原则

1. **每个组件只做一件事** — 如果一个组件有 3 个以上参数且存在 `if` 分支，拆分成多个组件
2. **组件接受 Theme 样式** — 不接受 `color`、`style` 等覆盖参数，样式全部来自 Theme 上下文
3. **const 构造器** — 所有组件必须能 `const` 构造
4. **无状态优先** — 能用 StatelessWidget 就不用 StatefulWidget
5. **测试覆盖** — 每个共享组件至少有一个 Widget 测试

### 3.3 复用规则（强制执行）

> 同类 UI 出现超过 **两次**时，必须抽象为共享组件，禁止复制粘贴。

**判定规则：**
- 同一个 `.dart` 文件中重复出现 2 次 → 提取为文件内私有 widget
- 不同 feature 中出现 2 次 → 提取到 `shared/widgets/`
- 不同页面中出现但将来可能用于其他 feature → 提取到当前 feature 的 `widgets/` 目录，不跨 feature 引用

**禁止行为：**
- ❌ 两个 feature 里各写一个几乎一样的 `Card` 样式
- ❌ 在 feature 页面中内联 `Container` + `BoxDecoration` 代替使用 `AppCard`
- ❌ 复制粘贴已有组件代码并修改样式参数

## 5. 模块边界

### 5.1 跨功能引用规则

```
features/diary/ ←→ features/today/     ❌ 不允许
features/day_counter/ ←→ features/today/ ❌ 不允许
features/diary/ ←→ core/               ✅ 允许
features/diary/ ←→ shared/widgets/     ✅ 允许
shared/widgets/ ←→ core/theme/         ✅ 允许
shared/widgets/ ←→ core/l10n/          ✅ 允许
```

**约束：** feature 之间不能相互引用。today 页通过 `Provider` 订阅多个 feature 的数据，但不直接引用 feature 的 Widget 或 Model。today 页的聚合数据通过 `today/providers/today_providers.dart` 中的 Provider 组合多个 feature 的 Repository 来实现。

### 5.2 新增 Feature 的步骤

1. 在 `features/` 下创建新的文件夹
2. 按 `model/` → `repository/` → `providers/` → `page.dart` → `widgets/` 顺序创建
3. 在 `core/database/database_helper.dart` 中添加新表
4. 在 `core/router/app_router.dart` 中添加路由
5. 在 `app.dart` 中更新底部导航

## 6. 样式系统

### 6.1 Theme 体系

```
MaterialApp.theme → ThemeData (Material 3)
    ├── colorScheme      # 颜色系统
    ├── textTheme        # 字体
    ├── cardTheme        # 全局 Card 样式
    ├── inputDecorationTheme  # 全局输入框样式
    └── extensions       # ThemeExtension（自定义 tokens）
```

### 6.2 禁止的硬编码模式 ❌

```dart
// ❌ 禁止：硬编码颜色
Container(color: Color(0xFF4F46E5))

// ❌ 禁止：硬编码间距
Padding(padding: EdgeInsets.all(16))

// ❌ 禁止：硬编码圆角
Container(decoration: BoxDecoration(borderRadius: BorderRadius.circular(12)))

// ❌ 禁止：硬编码字体大小
Text('hello', style: TextStyle(fontSize: 16, fontWeight: FontWeight.w600))

// ❌ 禁止：硬编码字符串
Text('保存')

// ❌ 禁止：Navigator.push 硬导航
Navigator.of(context).push(...)
```

### 6.3 正确的模式 ✅

```dart
// ✅ 正确：从 Theme 取颜色
Container(color: Theme.of(context).colorScheme.primary)

// ✅ 正确：使用间距常量
Padding(padding: EdgeInsets.all(AppSpacing.lg))

// ✅ 正确：Card 主题自动处理圆角
Card(child: ...)

// ✅ 正确：从 textTheme 取字体
Text('hello', style: Theme.of(context).textTheme.bodyLarge)

// ✅ 正确：GoRouter 声明式导航
context.go('/diary/edit')

// ✅ 正确：通过 l10n 取字符串
Text(AppLocalizations.of(context)!.save)
```

### 6.4 Context 扩展

通过 `context_extensions.dart` 提供快捷访问：

```dart
// 实际使用
context.colorScheme.primary       // 替代 Theme.of(context).colorScheme
context.textTheme.bodyLarge       // 替代 Theme.of(context).textTheme
context.isDarkMode                // 检查是否暗色模式
context.spacing                   // 替代 AppSpacing（可选）
```

## 8. 主题规则体系

### 8.1 ThemeExtension 自定义 Token

对于 MD3 不直接覆盖的场景（如 mood 不同等级的颜色），使用 ThemeExtension：

```dart
// core/theme/app_colors.dart
class AppColors extends ThemeExtension<AppColors> {
  final Color moodVerySad;
  final Color moodSad;
  final Color moodNeutral;
  final Color moodHappy;
  final Color moodVeryHappy;

  const AppColors({...});

  @override
  AppColors copyWith({...}) => AppColors(...);

  @override
  AppColors lerp(ThemeExtension<AppColors>? other, double t) {
    ...
  }

  // 浅色/深色预设
  static const light = AppColors(...);
  static const dark = AppColors(...);
}
```

使用方式：

```dart
final colors = Theme.of(context).extension<AppColors>()!;
Container(color: colors.moodHappy);
```

### 8.2 控件主题覆盖

全局控件样式在 `app_theme.dart` 中统一配置，不分散在各页面：

```dart
ThemeData(
  cardTheme: CardTheme(
    elevation: 0,
    shape: RoundedRectangleBorder(
      borderRadius: BorderRadius.circular(AppSpacing.md),
    ),
  ),
  inputDecorationTheme: InputDecorationTheme(
    border: OutlineInputBorder(
      borderRadius: BorderRadius.circular(AppSpacing.sm),
    ),
  ),
  filledButtonTheme: FilledButtonThemeData(
    style: FilledButton.styleFrom(
      shape: RoundedRectangleBorder(
        borderRadius: BorderRadius.circular(AppSpacing.sm),
      ),
    ),
  ),
)
```

## 10. 强制 Code Review 检查清单

每次提交前逐条检查：

- [ ] 无硬编码颜色（全部来自 `colorScheme` 或 `AppColors`）
- [ ] 无硬编码间距（全部引用 `AppSpacing`）
- [ ] 无硬编码字符串（全部走 l10n）
- [ ] 无 `Navigator.push` / `Navigator.pop`（全部走 GoRouter）
- [ ] 无重复 UI 模式（已检查共享组件库）
- [ ] 所有 Widget 使用 `const` 构造（不需要时）
- [ ] 共享组件有 Widget 测试
- [ ] 文件路径符合目录结构规范
- [ ] import 路径使用 `package:` 而不是相对路径
