# TraceLife V2 实施计划

> 目标：从个人工具 → 可用产品。V1 解决了"有"，V2 解决"好"。

---

## Phase 1: 数据安全（P0）

### 1.1 数据导出

| 任务 | 详情 |
|------|------|
| 导出 JSON | 全量导出 `diaries` + `day_counters` → 单个 `trace_life_backup.json` |
| 文件位置 | Android: `Downloads/trace_life_backup_2026-07-11.json`；Web: 浏览器下载 |
| UI 入口 | 设置页 → "导出数据" 按钮 |
| 格式 | `{"version":1,"exported_at":"...","diaries":[...],"day_counters":[...]}` |

### 1.2 数据导入

| 任务 | 详情 |
|------|------|
| 文件选择 | Android: `file_picker` 插件选择 JSON；Web: 文件上传 |
| 合并策略 | 按 `id` 去重 — 已有 id 跳过，新 id 插入 |
| 回滚保护 | 导入前备份当前数据库为临时文件，失败回滚 |

**新增依赖：** `file_picker`, `share_plus`

## Phase 2: 全文搜索（P1）

### 2.1 SQLite FTS5 全文索引

| 表 | 说明 |
|----|------|
| `diaries_fts` | FTS5 虚拟表，索引 `content` 字段 |
| 同步策略 | 触发器：INSERT/UPDATE/DELETE → 自动更新 FTS |

### 2.2 搜索 UI

| 组件 | 说明 |
|------|------|
| `SearchBar` | AppBar 顶部搜索框，输入即搜 |
| `SearchResultCard` | 搜索结果卡片，高亮关键词，点击跳转日记 |
| 搜索范围 | 日记内容 + 纪念日标题 |

## Phase 3: 本地推送提醒（P1）

### 3.1 纪念日提醒

| 规则 | 说明 |
|------|------|
| 触发时间 | 当天 9:00 AM |
| 提醒内容 | "🎂 XXX 的生日就在今天！" / "🎉 XXX 已过 N 天" |
| 实现 | `flutter_local_notifications` + 每日定时 |

### 3.2 日记提醒

| 规则 | 说明 |
|------|------|
| 触发时间 | 每天 21:00 |
| 提醒内容 | "今天还没有写日记哦 📝" |
| 可关闭 | 设置页 → 开关 |

**新增依赖：** `flutter_local_notifications`, `workmanager`（后台定时）

---

## Phase 4: 数据统计（P2）

### 4.1 心情趋势

| 功能 | 说明 |
|------|------|
| 周报 | 最近 7 天心情曲线（折线图） |
| 月报 | 本月日记篇数 + 平均心情 |
| 热力图 | 日历热力图（写日记的天数密度） |
| 组件 | `fl_chart` |

### 4.2 统计入口

- Today 首页底部新增统计卡片
- 点击进入统计详情页

**新增依赖：** `fl_chart`

## Phase 6: 图片支持（P2）

### 6.1 日记插图

| 功能 | 说明 |
|------|------|
| 插入图片 | 日记编辑页增加图片按钮 → 拍照/相册 |
