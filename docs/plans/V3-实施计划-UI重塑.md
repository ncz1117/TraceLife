# TraceLife V3 实施计划 — UI 重塑

> 目标：从"能用的工具"→"想天天打开的产品"。V2 解决了功能完整，V3 解决体验与情感。

---

## 当前问题诊断

| 痛点 | 现象 | 业务影响 |
|------|------|----------|
| 品牌感缺失 | Material 3 默认蓝配色 | 看着像"教学项目" |
| 视觉层次单薄 | 扁平卡片，无阴影/圆角区分 | 重点信息不突出 |
| 缺乏情感化 | 无插画、无空状态文案 | 新用户上手冷冰冰 |
| 缺动效 | 切换生硬，列表无渐入 | "生命感"缺失 |
| 字体单一 | 默认 Roboto | 缺个性、标题与正文无对比 |
| 跨平台不一致 | emoji 渲染差异 | Android/iOS 表现不同 |

---

## 设计参考

- **主基调**：Notion 温暖极简（背景柔和、字体易读）
- **信息架构**：Apple Journal 编辑感（电影感图片、优雅排版）
- **交互细节**：Airbnb 圆润（卡片/按钮柔和）
- **数据呈现**：Linear 精准（统计图表紧凑专业）

## Phase 1：设计令牌（1 天）

### 1.1 颜色系统

| 类别 | 数量 | 说明 |
|------|------|------|
| 主色 | 4 套预设 | 默认青/暖橙/樱粉/暗夜紫，用户可切换 |
| 中性色 | 8 级 | 背景层、表面层、文本层 |
| 功能色 | 5 种 | 成功/警告/错误/信息/链接 |
| 心情色 | 5 个 | 1-5 心情对应色阶 |

```dart
// 主题结构（概念）
class AppTheme {
  final ColorScheme colors;       // 颜色
  final TextTheme textStyles;     // 字体
  final SpacingScale spacing;     // 间距
  final RadiusScale radii;        // 圆角
  final ShadowScale shadows;      // 阴影
}
```

### 1.2 字体系统

| 角色 | 字体 | 备选 |
|------|------|------|
| 标题 | 思源宋体 (Source Han Serif) | Noto Serif SC |
| 正文 | 思源黑体 (Source Han Sans) | Noto Sans SC |
| 数字 | DM Mono | JetBrains Mono |
| 强调 | 思源宋体 Heavy | 700 字重 |

**集成方式**：`google_fonts` 包，本地缓存。

### 1.3 间距 / 圆角 / 阴影

```dart
// 间距
4 / 8 / 12 / 16 / 24 / 32 / 48

// 圆角
sm: 8    // 按钮、标签
md: 12   // 输入框
lg: 16   // 卡片
xl: 24   // 大卡片、底部弹窗

// 阴影
xs: 0 1 2 rgba(0,0,0,0.04)
sm: 0 2 8 rgba(0,0,0,0.06)
md: 0 4 16 rgba(0,0,0,0.08)
lg: 0 8 32 rgba(0,0,0,0.12)
```

### 1.4 文件结构

```
lib/core/theme/
├── app_theme.dart           # 主题入口
├── app_colors.dart          # 颜色定义
├── app_typography.dart      # 字体定义

├── app_shadows.dart         # 阴影 token
└── presets/
    ├── default_theme.dart   # 默认青
    ├── warm_theme.dart      # 暖橙
    ├── pink_theme.dart      # 樱粉
    └── dark_theme.dart      # 暗夜紫
```

## Phase 5：动效设计（0.5 天）

### 5.1 页面切换

| 切换类型 | 动画 |
|---------|------|
| 同级 Tab | 淡入淡出 200ms |
| 推入详情 | 水平滑动 + 透明度 300ms |
| 弹窗 | 缩放 + 淡入 250ms |
| 返回 | 滑动 250ms |

**实现**：`GoRouter` 的 `pageBuilder` + `CustomTransitionPage`。

### 5.2 列表项

- 渐入：`AnimatedList` + 错峰 30ms
- 删除：缩放 + 淡出
- 新增：从顶部滑入

### 5.3 按钮反馈

- 按压：缩放 0.96 + 100ms
- 涟漪：Material 默认
- 加载：内嵌旋转图标

### 5.4 心情选择

- 选中：弹跳 + 颜色填充
- 切换：交叉淡入淡出

## Phase 6：暗色模式适配（0.5 天）

| 元素 | 浅色 | 暗色 |
|------|------|------|
| 背景 | 暖白 #FAFAF7 | 真黑 #0A0A0A |
| 表面 | 纯白 #FFFFFF | 深灰 #1A1A1A |
| 文字 | 深灰 #1F1F1F | 浅灰 #E5E5E5 |
| 主色 | 饱和度 70% | 饱和度 80% |
| 阴影 | 黑色透明 | 黑色 + 边缘高光 |

**跟随系统**：`MediaQuery.platformBrightnessOf(context)` 自动切换。

## 不做事项（明确边界）

- ❌ 复杂 3D 动效（性能成本不划算）
- ❌ 视频背景（占用空间）
- ❌ 自定义字体（仅用 Google Fonts）
- ❌ 桌面端专门适配（仍以移动端优先）
