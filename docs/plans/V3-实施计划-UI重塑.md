# TraceLife V3 实施计划 — UI 重塑

> 目标：从"能用的工具"→"想天天打开的产品"。V2 解决了功能完整，V3 解决体验与情感。

> ## ✅ 状态：已完成（2026-07-12）
> **评分**：12/20 → **17.5/20**（+5.5, +46%）
> **耗时**：1 天（密集 8 个命令）
> **详细见**：[RELEASE.md#v30--ui-重塑已完成--](../../RELEASE.md)

---

## 当前问题诊断

| 痛点 | 现象 | 业务影响 |
|------|------|----------|
| 品牌感缺失 | Material 3 默认蓝配色 | 看着像"教学项目" |
| 视觉层次单薄 | 扁平卡片，无阴影/圆角区分 | 重点信息不突出 |
| 缺乏情感化 | 无插画、无空状态文案 | 新用户上手冷冰冰 |
| 缺动效 | 切换生硬，列表无渐入 | "生命感"缺失 |
| 字体单一 | 默认 Roboto | 缺个性、标题与正文无对比 |
| 跨平台不一致 | emoji 渲染差异 | Android/iOS 表现不同 |

---

## 设计参考

- **主基调**：Notion 温暖极简（背景柔和、字体易读）
- **信息架构**：Apple Journal 编辑感（电影感图片、优雅排版）
- **交互细节**：Airbnb 圆润（卡片/按钮柔和）
- **数据呈现**：Linear 精准（统计图表紧凑专业）

## Phase 1：设计令牌（1 天）

### 1.1 颜色系统

| 类别 | 数量 | 说明 |
|------|------|------|
| 主色 | 4 套预设 | 默认青/暖橙/樱粉/暗夜紫，用户可切换 |
| 中性色 | 8 级 | 背景层、表面层、文本层 |
| 功能色 | 5 种 | 成功/警告/错误/信息/链接 |
| 心情色 | 5 个 | 1-5 心情对应色阶 |

```dart
// 主题结构（概念）
class AppTheme {
  final ColorScheme colors;       // 颜色
  final TextTheme textStyles;     // 字体
  final SpacingScale spacing;     // 间距
  final RadiusScale radii;        // 圆角
  final ShadowScale shadows;      // 阴影
}
```

### 1.2 字体系统

| 角色 | 字体 | 备选 |
|------|------|------|
| 标题 | 思源宋体 (Source Han Serif) | Noto Serif SC |
| 正文 | 思源黑体 (Source Han Sans) | Noto Sans SC |
| 数字 | DM Mono | JetBrains Mono |
| 强调 | 思源宋体 Heavy | 700 字重 |

**集成方式**：`google_fonts` 包，本地缓存。

### 1.3 间距 / 圆角 / 阴影

```dart
// 间距
4 / 8 / 12 / 16 / 24 / 32 / 48

// 圆角
sm: 8    // 按钮、标签
md: 12   // 输入框
lg: 16   // 卡片
xl: 24   // 大卡片、底部弹窗

// 阴影
xs: 0 1 2 rgba(0,0,0,0.04)
sm: 0 2 8 rgba(0,0,0,0.06)
md: 0 4 16 rgba(0,0,0,0.08)
lg: 0 8 32 rgba(0,0,0,0.12)
```

## Phase 5：动效设计（0.5 天）

### 5.1 页面切换

### H. 风险与权衡

| 风险 | 概率 | 应对 |
|------|------|------|
| google_fonts 加载慢 | 中 | 缓存 + fallback Roboto |
| SVG 渲染性能 | 中 | 仅用于静态插画，不用在列表 |
| 4 套主题维护成本 | 中 | 用 ColorScheme 种子色派生 |
| 动效掉帧 | 低 | 关闭 `prefers-reduced-motion` |
| Web 字体体积 | 中 | 仅加载用到的字重 |
